## 📜 Platform Rules & Guarantees

### 🕒 7-Day Pass Rule
Premium pass is valid for **7 days**.  
Users can view **unlimited rooms** during this period.

### 💸 Zero Brokerage Policy
No middlemen. Direct connection between owner and tenant.

### 🔐 Security Protocol
Listings are monitored, but users should verify details before booking.
