**Decentralized Rental Platform for Global Room Discovery & Listing**  
Powered by Web3 ⚡ | Built on **Aptos** + **Shelby Protocol**

---

## 🚀 Overview

**RoomSathi** is a decentralized rental platform that allows users to:

- 🌍 Discover rooms globally
- 🏡 List their own properties
- 🔐 Make secure Web3 payments using **APT** & **Shelby USD**
- 📄 Manage rental agreements (coming soon)

---

## ✨ Features

- 🔗 Wallet Connect (Petra Wallet)
- 💸 Web3 Payments (APT + Shelby USD) – *In Progress*
- 📊 Budget Planning & Comparison Tools
- 🌙 Dark Mode Support
- 🌐 Multi-language Support
- 🎨 Modern UI/UX with smooth animations
- 📱 Fully Responsive Design

---

## 🧠 Tech Stack

- **Frontend:** React + TypeScript
- **Build Tool:** Vite
- **Styling:** CSS (Responsive Design)
- **Blockchain:** Aptos
- **Protocol:** Shelby Protocol
- **Wallet:** Petra Wallet
