# 🚀 Overview

**RoomSathi** is a modern **Web3-based decentralized rental platform** that enables users to discover, list, and manage rental properties globally while ensuring transparency, security, and decentralized ownership.

### ✨ What You Can Do

- 🌍 Discover rental rooms worldwide
- 🏡 List your own property
- 🔐 Secure login with Petra Wallet
- 💰 Pay using **APT** & **Shelby USD**
- 📊 Compare rental budgets
- 🌐 Multi-language support
- 🌙 Beautiful Dark Mode
- 📱 Fully Responsive Design
- 📄 Smart Rental Agreements *(Coming Soon)*

# 🛠️ Installation

### 📥 Clone Repository

```bash
git clone https://github.com/Savita06061/roomsathi.git
```

### 📂 Open Project

```bash
cd roomsathi
```

### 📦 Install Dependencies

```bash
npm install
```

### ▶️ Run Development Server

```bash
npm run dev
```

### 🌐 Open Browser

```
http://localhost:5173
```
